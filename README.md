# Movie Reservation System

A movie reservation system built with Python and SQLite.

## Features

* User registration and login
* Admin and regular user roles
* Movie and showtime management
* Seat reservations and cancellations
* Reservation and revenue reports
* Password hashing
* SQLite database


## How to Run

1. Download or clone this repository.
2. Open the project folder in Python IDLE or a terminal.
3. Run `init_db.py` to create the database tables.
4. Run `app.py` to start the application.

## Technologies Used

* Python
* SQLite
